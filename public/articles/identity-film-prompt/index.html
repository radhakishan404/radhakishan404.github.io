## Motion system

- Everything is frame-driven with `kf(frame, [[f, value], …], ease)` tables. No CSS transitions, timers, `Math.random` or `Math.floor` on motion.
- Entrances use exponential ease-out. Exits accelerate (ease-in). Nothing enters or leaves static.
- Blur always matches real velocity: horizontal motion gets horizontal blur, vertical gets vertical, zoom gets a smear of 20–30 progressively scaled copies. Use SVG `feGaussianBlur` with `filterUnits="userSpaceOnUse"` and a large filter region. When a shot is time-stretched, scale the blur by the speed so it still matches on-screen velocity.
- Blur never destroys the silhouette.
- Banned: crossfade, dissolve, generic zoom, glitch, RGB split, spinning logos, random particles, presets, frozen frames.
- Allowed transitions: push-through, whip, scale collapse, directional blur, object morph, UI morph, depth pass.
- 35 s version: build a segment table in beats at 124 BPM so every cut lands on the score. Stretch the shots, don't speed them up. Its pace should feel calmer than the 12 s version.

## Sound

- No voiceover, no copyrighted music
- Synthesize an original minimal electronic score at 124 BPM:
  - soft pad intro and a riser into the first impact
  - kicks from S2, then hats and plucks building through the developer and content shots
  - bigger hits on each major cut
  - a shimmer on the brand and end card
- SFX: identity reveal, soft impacts, clicks, UI ticks, activation, subtle whooshes, sub drops on the key cuts, final shimmer. Keep them below the music, never aggressive.
- Master to −14 LUFS, −1 dBTP. Fade only over the final ~60 ms.

## Process

1. First, tell me what each shot will show and which facts it uses. No code yet.
2. After I approve, render four stills: S1 name reveal, S2 years, S5 developer/AI, S9 YouTube/creator. Fix anything inconsistent.
3. Then render all three aspect ratios in 4K with audio. One final file per ratio, no review or test exports.
