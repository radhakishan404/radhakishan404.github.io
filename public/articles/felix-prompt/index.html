From the reel · Claude prompt

The prompt an Anthropic engineer uses. Copy it below.

Felix Rieseberg works on Claude at Anthropic. In a post on his own blog he shared a short prompt he uses to get deeper, expert-level work out of Claude. You paste it after your request, and Claude rewrites your prompt the way a top professional would have written it.

Your first prompt
is missing things.

When you ask Claude for something, it does what you asked. The problem is what you didn't ask. A top professional would add steps, data and checks that never occur to most of us, so the result comes out average.

Felix calls this being ambitious in depth: getting the model to use the tools, methods and raw material the best people in a field would use. His prompt makes Claude spell those out first, then turn them into a better prompt for you.

The prompt

Paste this after your request.

COPY · FELIX'S PROMPT

Word for word, from his post

COPY PROMPT

I want a deeper version of this task, not a bigger one. Before rewriting it: (1) say what a top professional in this field would do here that I'm not asking for; (2) name the rawest material they would start from instead of what has already been digested for me; (3) name the specific methods and tools they would use; (4) say what, other than you or me, would show the result is right. Then rewrite my prompt to ask for exactly that.

How to use it

Three steps.

01

Write your request

Say what you want to make, as you normally would: a website, a script, a report.

02

Paste the prompt after it

Claude lists what an expert would add, the raw material, the methods and tools, and how to check the result. Then it rewrites your prompt.

03

Run the new prompt

Read the rewrite, fix anything that doesn't fit, then give it back to Claude and let it build.

What it asks for

The four questions.

EXPERT

What would a pro add?

The steps a top professional would take that you didn't ask for.

RAW

Where would they start?

The rawest material: real data, logs, sources, not a summary someone already made.

TOOLS

Which methods and tools?

The specific methods and tools a pro would use, not just pro-sounding words.

CHECK

What proves it's right?

Something other than you or Claude: a test, a benchmark, real users, a tool that gives feedback.

Example

Before and after.

YOUR REQUEST

Make me an animated landing page for my app.

+ FELIX'S PROMPT, AND CLAUDE COMES BACK WITH THINGS LIKE

A designer would start from your real product screenshots and copy, not placeholder text; plan the animation around one clear story; use a proper motion library and real performance budgets; and check the result with a Lighthouse score and a test on a real phone. Then it hands you a rewritten prompt that asks for all of that.

Tips from the post

Get more out of it.

GOALS

Ask for more than seems reasonable

Felix's example: need a page to load in 5s instead of 10s? Ask for 200ms.

JUDGE

Don't let it grade itself

He asks for outside validation, ideally a tool Claude can run to get feedback right away.
