Instagram's new post sizes: what to upload now

Square-by-default is no longer the safest creator workflow. Instagram is vertical-first, profile grids now reward 3:4 thinking, and Stories/Reels still need real safe zones so your text does not get buried under UI.

Updated Jul 2, 2026 7-slide visual guide Feed + carousel + Reels + Stories rk.codex

The short answer

Feed + carouselUse 1080 x 1440 for 3:4 creator posts when supported. Keep 1080 x 1350 as your compatibility fallback.
Grid previewDesign as if your profile grid preview is 3:4. Keep faces, headlines, and CTAs centered.
Stories + ReelsUse 1080 x 1920. Keep key text away from the top, bottom, and right-side UI zones.
Practical caveat: public size guidance is not perfectly unified. Some creator guides now recommend 3:4 / 1080 x 1440 for feed and grid consistency, while many official ads and scheduling flows still document 4:5 / 1080 x 1350 as the safer feed format. Test your own account and toolchain before replacing every template.

How to design posts that survive every crop

1. Treat the first slide as the crop contract

The first carousel slide sets the format. If slide one is 3:4, keep the whole carousel in that same canvas. Mixing sizes creates unpredictable previews and weak swipe rhythm.

2. Keep headlines large and centered

Design for the grid preview first. Put the hook, face, product, or main visual in the center 70 percent of the frame. Avoid important text near the bottom edge because captions, buttons, and preview crops can cover it.

3. Export sharper than the minimum

The attached slides are 1086 pixels wide, which is close to the common 1080-pixel target. For production templates, export at exactly 1080 x 1440 for 3:4 or 1080 x 1350 for 4:5. Keep text crisp, use sRGB, and avoid tiny thin type.

4. Reels and Stories are not the same as feed posts

Reels and Stories still use 1080 x 1920. The canvas is full-screen, but the usable safe area is smaller because Instagram overlays profile UI, captions, reply bars, buttons, and engagement controls.

5. Always preview the grid

Before posting, check the profile grid preview. If the post looks good there, it usually works in the feed too. If it only looks good in the editor, it is not done.

Copy-ready posting checklist

Instagram post size checklist

Feed / carousel:
- Prefer 1080 x 1440 for 3:4 creator posts.
- Use 1080 x 1350 if a tool, ad flow, or scheduler rejects 3:4.
- Keep the first carousel slide and all later slides the same size.
- Keep hook text, face, and CTA centered.
- Avoid important text near the bottom edge.

Reels / Stories:
- Export 1080 x 1920.
- Keep hooks, faces, captions, logos, and CTAs inside the center safe zone.
- Leave top and bottom space for Instagram UI.
- Check the cover/grid preview before publishing.

Final QA:
- View at phone size.
- Check text readability at thumbnail size.
- Check the profile grid crop.
- Save the post and share test if needed.
