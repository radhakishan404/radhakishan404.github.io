What is Fugu — and why does it exist

On June 12, 2026, Anthropic suspended access to Fable 5 and Mythos Preview globally due to US government export controls. Developers outside America lost access overnight. No warning. No transition period.

Ten days later, on June 22, Tokyo-based Sakana AI released Fugu — named after the Japanese blowfish. The fish that looks harmless on the surface and is lethally complex underneath. The name is deliberate.

Sakana AI was founded in 2023 by Llion Jones and David Ha. Jones co-authored the 2017 Transformer paper — "Attention Is All You Need" — the research that built the foundation for every AI model that exists today. He left Google, went to Tokyo, and built Sakana around a completely different philosophy: instead of training bigger and bigger single models, study how nature works. Fish schools. Ant colonies. Swarm intelligence. Use that to build AI that coordinates rather than brute-forces.

Sakana AI is now valued at $2.5 billion, backed by NVIDIA and Google. Fugu is their first commercial product for everyday developers.

How it actually works — the conductor model

Every AI model you've used works the same way. One model. You send a prompt. It answers. Done.

Fugu is architecturally different. It is not a bigger model. It is a coordinator — a 7 billion parameter model trained specifically to manage other models.

1
You send one prompt
To you it looks like any other API call. Same format as OpenAI. One endpoint. One request.
2
Fugu reads the task and decides
The 7B Conductor model analyses your prompt. Simple task? Answer directly. Complex multi-step task? Assemble a team.
3
Specialists get assigned
Fugu picks from a pool of frontier models — GPT-5, Gemini 3.1, Claude Opus, specialist open models. Each sub-task goes to the model best suited for it. TRINITY assigns roles: Thinker, Worker, Verifier.
4
Outputs get cross-checked
The Verifier role checks every output. Fugu can even call itself recursively — checking its own coordination decisions before synthesising the final answer.
5
One clean answer comes back
You receive one response. No orchestration complexity in your code. No managing multiple APIs. The entire multi-agent system is invisible to you.

This is built on two ICLR 2026 research papers: TRINITY (evolved LLM coordinator) and Conductor (learning to orchestrate agents using reinforcement learning). Not marketing. Peer-reviewed published research.

Key difference from model routers Tools like RouteLLM or Not Diamond pick one model per prompt — routing. Fugu coordinates multiple models on the same prompt in parallel and sequence, synthesises their outputs, and verifies before returning. That's orchestration, not routing. Different category entirely.

Using the API — code example

Fugu uses the OpenAI-compatible Chat Completions format. If you already use GPT or Claude in code, swap the base URL and API key. Nothing else changes.

from openai import OpenAI

# Get your API key from console.sakana.ai
client = OpenAI(
    base_url="https://<your-fugu-endpoint>/v1",
    api_key="YOUR_SAKANA_API_KEY",
)

resp = client.chat.completions.create(
    model="fugu-ultra-20260615",  # or "fugu" for standard
    messages=[
        {"role": "user", "content": "Review this codebase for security issues."},
    ],
)

print(resp.choices[0].message.content)
# Token usage and cost reported per request

Get your endpoint and API key from console.sakana.ai. Model IDs: fugu-ultra-20260615 for Ultra, fugu for standard.

Already using Claude or GPT in your code? Change base_url to your Fugu endpoint. Change api_key to your Sakana key. Change model to fugu-ultra-20260615. That's the entire migration.

Honest limitations

Latency. Multiple API calls behind the scenes means Fugu is slower than a single model call. For real-time interactive chat this adds up. Best suited to tasks where quality matters more than response speed.

Cost on heavy tasks. Per-message costs can reach $10 on demanding Fugu Ultra tasks with long multi-agent chains. For teams running heavy research automation, monitor spend carefully via the per-request cost reporting.

Closed pool composition. Sakana has not disclosed what percentage of the agent pool is closed vs open models. You don't know exactly which models ran on your task unless you opt specific providers out. Transparency here needs to improve before enterprise production use.

Benchmark fairness disputes. The community on Hacker News and X has flagged that Fugu's benchmarks compare against provider-reported scores, not head-to-head identical test setups. Treat scores as directional. Run your own evaluations on your actual tasks.

No EU access yet. GDPR compliance is in progress. Timeline not published.

Frequently asked questions

Is this just a model router like RouteLLM? ▼
No. Routers pick one model per prompt and send it there. Fugu coordinates multiple models on the same prompt — in parallel and sequence — cross-checks outputs, and synthesises. Architecturally different. Routers make one selection. Fugu runs a multi-agent workflow.
Can I use it if I'm in India? ▼
Yes. Full access. No restrictions. Only excluded regions right now are EU and EEA due to pending GDPR compliance work. India, US, Southeast Asia, Japan — all available today.
Does it actually match Fable 5? ▼
Sakana claims parity. Independent verification doesn't exist yet because Fable 5 is export-controlled and not in Fugu's model pool — they can't run head-to-head tests. On the models it CAN benchmark against — GPT-5.5, Opus 4.8, Gemini 3.1 — it leads on 10 of 11 benchmarks. Judge on those numbers for now.
What's the difference between Fugu and Fugu Ultra? ▼
Fugu — optimised for speed and everyday tasks. Lower latency. Good for chatbots, code review, interactive coding. Supports provider opt-out. Fugu Ultra — optimised for maximum quality on hard multi-step tasks. Deeper agent pool. Fixed pool — no opt-out. Best for research, security assessments, long-horizon automation. Both included in every subscription tier.
Who founded Sakana AI? ▼
Llion Jones — co-author of the 2017 Transformer paper "Attention Is All You Need," the research that underpins all modern AI. And David Ha — former Research Director at Google Brain. They left to build Sakana AI in Tokyo in 2023, focused on biomimicry and swarm intelligence rather than scaling single models.
Is it open source? ▼
No. Fugu is a commercial closed-source product. The underlying research papers — TRINITY and Conductor — are published and peer-reviewed at ICLR 2026. But the orchestration logic and model pool composition are proprietary. This is a legitimate criticism for teams that need full transparency.
