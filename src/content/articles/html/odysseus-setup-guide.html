What is Odysseus?

Odysseus kya hai?

Felix Kjellberg — the Swedish YouTuber known worldwide as PewDiePie, with over 110 million subscribers — quietly spent over a year building an AI tool. On May 31, 2026, he released it publicly with four words: "The war on big tech has just begun."

Felix Kjellberg — jise poori duniya PewDiePie ke naam se jaanti hai, 110 million subscribers ke saath — ne ek saal se zyada time silently ek AI tool banane mein lagaya. 31 May 2026 ko unhone ise publicly release kiya sirf chaar shabdon ke saath: "The war on big tech has just begun."

Odysseus is a self-hosted AI workspace. Think of it as your own private version of ChatGPT that runs entirely on your computer. No data leaves your machine. No monthly subscription. No company reading your conversations.

Odysseus ek self-hosted AI workspace hai. Socho jaise tumhara apna private ChatGPT jo bilkul tumhare computer pe chalta hai. Koi data bahar nahi jaata. Koi monthly subscription nahi. Koi company tumhari conversations nahi padh rahi.

It is not just a chatbot. It bundles deep research, AI agents, email management, document tools, and a model manager — all in one place.

Ye sirf chatbot nahi hai. Ismein deep research, AI agents, email management, document tools, aur ek model manager — sab ek jagah hai.

What Can It Actually Do?

Ye Actually Kya Kar Sakta Hai?

1. Chat (like ChatGPT, but private)

1. Chat (ChatGPT jaisa, lekin private)

Talk to any local AI model you install. No API key needed if you use Ollama locally. You can also connect OpenAI or Anthropic keys if you want frontier model power through the same interface.

Kisi bhi local AI model se baat karo jo tumne install kiya hai. Ollama use karo toh koi API key nahi chahiye. Agar chahein toh OpenAI ya Anthropic keys bhi connect kar sakte ho same interface mein.

2. Deep Research

2. Deep Research

Give it a topic. It goes out, reads multiple real sources from the web, and comes back with a structured, cited research report. Much better than asking a chatbot to "summarize" something it doesn't know.

Koi topic do. Ye web pe real sources padhta hai aur ek structured, cited research report lekar aata hai. Chatbot se "summarize" karne se kaafi behtar hai kisi aisi cheez ke liye jo use pata hi nahi.

3. AI Agent

3. AI Agent

The agent can browse the web, read and write files on your computer, run shell commands, and chain multiple tasks together. You describe what you want done — it figures out the steps and does them.

Agent web browse kar sakta hai, tumhare computer pe files padh aur likh sakta hai, shell commands run kar sakta hai, aur multiple tasks ek saath handle kar sakta hai. Tum batao kya karna hai — ye steps figure out karke karta hai.

4. Cookbook (Best Feature)

4. Cookbook (Sabse Badhiya Feature)

This scans your GPU and VRAM, then recommends the best AI model your hardware can actually run — and downloads it for you in one click. No more guessing which 7B or 13B model will fit in your memory.

Ye tumhara GPU aur VRAM scan karta hai, phir recommend karta hai ki kaunsa AI model tumhara hardware actually run kar sakta hai — aur ek click mein download kar deta hai. Ab guess karne ki zaroorat nahi ki kaunsa 7B ya 13B model tumhari memory mein fit hoga.

5. Email Triage + Calendar + Notes

5. Email Triage + Calendar + Notes

Connect your email and let Odysseus sort urgent from non-urgent. It also has calendar and note-taking built in — all local, all private.

Email connect karo aur Odysseus ko urgent aur non-urgent sort karne do. Ismein calendar aur note-taking bhi built in hai — sab local, sab private.

Step 0 — Install Prerequisites

Step 0 — Prerequisites Install Karo

Git

Git

Git is how you download the Odysseus code from GitHub. Check if you already have it by running this in your Terminal:

Git se tum GitHub se Odysseus code download karte ho. Check karo ki tumhare paas already hai ya nahi apne Terminal mein yeh run karke:

git --version

If you see a version number, you are ready. If not, download from git-scm.com.

Agar version number dikh raha hai, tum ready ho. Nahi toh git-scm.com se download karo.

Docker

Docker

Docker packages Odysseus into a self-contained container so you don't need to manually install every dependency. Think of it as a pre-packed box where everything Odysseus needs is already inside. Download from docker.com and install it normally.

Docker Odysseus ko ek self-contained container mein pack karta hai taaki tumhe manually har dependency install na karni pade. Socho jaise ek pre-packed dabba jisme Odysseus ki zaroorat ki sab cheez already andar hai. docker.com se download karo aur normally install karo.

1
Clone the Repository
Repository Clone Karo

"Cloning" just means downloading all the project files to your computer. Open your Terminal and run these two commands one by one:

"Cloning" ka matlab hai saare project files apne computer pe download karna. Terminal kholo aur ye do commands ek-ek karke run karo:

git clone https://github.com/pewdiepie-archdaemon/odysseus.git
cd odysseus

The first command downloads everything. The second command moves you inside the folder it just created. You must be inside this folder for all the next steps.

Pehli command sab kuch download karti hai. Doosri command tumhe abhi create hue folder ke andar le jaati hai. Agle saare steps ke liye tum isi folder ke andar hone chahiye.

2
Set Up Your Configuration File
Configuration File Setup Karo

The .env file is where Odysseus stores its settings — things like which port to run on and your admin username. Create it from the provided template with this command:

.env file wo jagah hai jahan Odysseus apni settings store karta hai — jaise kaunse port pe run karna hai aur tumhara admin username. Is command se provided template se banao:

cp .env.example .env

Open the .env file in any text editor (Notepad, VS Code, whatever you use). For most people, the default settings work fine and no editing is needed. But if you want to customize:

.env file ko kisi bhi text editor mein kholo (Notepad, VS Code, jo bhi use karte ho). Zyaadatar logo ke liye default settings theek kaam karti hain aur editing ki zaroorat nahi. Lekin agar customize karna chahte ho:

SettingWhat it does SettingKya karta hai
APP_PORT=7001 Change this if port 7000 is already in use on your machine Ise change karo agar port 7000 tumhare machine pe already use ho raha hai
ODYSSEUS_ADMIN_USER=yourname Set a custom admin username instead of the default "admin" Default "admin" ki jagah custom admin username set karo
AUTH_ENABLED=true Keep this true — do not expose Odysseus to the internet without auth Ise true rakhna — auth ke bina Odysseus ko internet pe expose mat karo
3
Build and Run with Docker
Docker se Build aur Run Karo

This single command builds Odysseus and starts it up. The first time you run this, it may take a few minutes as Docker downloads everything it needs. That is completely normal.

Yeh ek command Odysseus build karti hai aur start karti hai. Pehli baar run karne par kuch minutes lag sakte hain kyunki Docker sab kuch download karta hai. Yeh bilkul normal hai.

docker compose up -d --build

You will see lines of output scrolling past — that is fine. Wait until it stops. The -d flag runs it in the background so your Terminal stays free after it starts.

Tumhe output ki lines scroll hote dikhenge — yeh theek hai. Ruko jab tak band ho jaye. -d flag ise background mein run karta hai taaki tumhara Terminal start hone ke baad free rahe.

4
Open Odysseus in Your Browser
Browser mein Odysseus Kholo

Once Docker finishes, open any browser — Chrome, Firefox, Safari — and go to:

Docker khatam hone ke baad, koi bhi browser kholo — Chrome, Firefox, Safari — aur yahan jao:

http://localhost:7000

Odysseus will load. On your first login, it will create a temporary admin password and print it in the terminal. Find it by running:

Odysseus load hoga. Pehle login par, ye ek temporary admin password create karega aur terminal mein print karega. Ise dhundho yeh run karke:

docker compose logs odysseus | grep -i password

Use that password to log in, then immediately change it in Settings. Use a strong password — do not leave it as the default.

Us password se login karo, phir Settings mein turant change karo. Strong password use karo — default mat rakhna.

5
Connect a Local AI Model with Ollama
Ollama se Local AI Model Connect Karo

Odysseus works best when paired with Ollama — a free tool that runs AI models directly on your own hardware. No internet needed, no API key, no cost.

Odysseus tab sabse accha kaam karta hai jab Ollama ke saath pair kiya jaye — ek free tool jo AI models seedha tumhare hardware pe run karta hai. Internet ki zaroorat nahi, koi API key nahi, koi cost nahi.

Download Ollama from ollama.com and install it. Then pull a model:

Ollama ko ollama.com se download karo aur install karo. Phir ek model pull karo:

# For a good balance of speed and quality (needs ~8GB VRAM)
ollama pull llama3

# If your GPU is weaker, try a smaller model
ollama pull phi3

Then in Odysseus Settings, point it to Ollama's server address:

Phir Odysseus Settings mein, ise Ollama ke server address pe point karo:

http://localhost:11434

Done. Your AI is now completely local — no cloud, no subscription, no data leaving your machine.

Ho gaya. Tumhara AI ab completely local hai — koi cloud nahi, koi subscription nahi, koi data tumhare machine se bahar nahi jata.

Not sure which model to use? Confirm nahi kaunsa model use karein? Use the Cookbook feature inside Odysseus. It scans your GPU automatically and recommends the best model for your exact hardware. Odysseus ke andar Cookbook feature use karo. Ye tumhara GPU automatically scan karta hai aur tumhare exact hardware ke liye best model recommend karta hai.

On a Mac? Use This Instead

Mac Pe Ho? Ye Use Karo

Mac users with an M-series chip (M1, M2, M3, M4) should use the native launcher instead of Docker for GPU acceleration. Docker on macOS cannot use the Metal GPU.

M-series chip (M1, M2, M3, M4) wale Mac users ko GPU acceleration ke liye Docker ki jagah native launcher use karna chahiye. macOS pe Docker Metal GPU use nahi kar sakta.

git clone https://github.com/pewdiepie-archdaemon/odysseus.git
cd odysseus
./start-macos.sh

It will launch at http://127.0.0.1:7860 instead of port 7000.

Ye http://127.0.0.1:7860 pe launch hoga port 7000 ki jagah.

Is It Safe?

Kya Ye Safe Hai?

Yes — with the standard care you would apply to any self-hosted software. Here is why it is trustworthy by design:

Haan — us standard care ke saath jo tum kisi bhi self-hosted software pe lagate ho. Yahan bataya hai ki design se ye trustworthy kyun hai:

Open source — Every line of code is public. With 45,000+ stars and thousands of forks, the code has been reviewed by many developers. No hidden backdoors can survive that level of scrutiny.

Open source — Code ki har line public hai. 45,000+ stars aur hazaron forks ke saath, kaafi developers ne code review kiya hai. Itne scrutiny mein koi hidden backdoor survive nahi kar sakta.

No telemetry — Odysseus does not phone home. It does not track your usage, your conversations, or anything else.

No telemetry — Odysseus phone home nahi karta. Ye tumhara usage, tumhari conversations, ya koi bhi cheez track nahi karta.

No account required — No email sign-up, no external platform. Everything stays on your machine.

Koi account required nahi — Koi email sign-up nahi, koi external platform nahi. Sab tumhari machine pe rehta hai.

Keep in mind Dhyan mein rakho Do not expose Odysseus to the public internet. Keep it on localhost or a trusted private network only. Always change your admin password after first login. Only grant the AI agent access to folders you are comfortable with it reading. Odysseus ko public internet pe expose mat karo. Ise sirf localhost ya trusted private network pe rakhna. Pehle login ke baad hamesha admin password change karo. AI agent ko sirf un folders ka access do jinhe tum padwane mein comfortable ho.

Frequently Asked Questions

Aksar Pooche Jaane Wale Sawaal

Is Odysseus completely free? Kya Odysseus bilkul free hai? ▼

Yes. MIT license. No paid tier, no subscription, no premium features behind a paywall. The only cost is the electricity your computer uses to run the AI model.

Haan. MIT license. Koi paid tier nahi, koi subscription nahi, koi premium features paywall ke peeche nahi. Sirf wo electricity cost hai jo tumhara computer AI model run karne mein lagata hai.

Does it require internet to work? Kya ise kaam karne ke liye internet chahiye? ▼

Not for core features. Once you have a local model running through Ollama, everything works offline. The only exception is the Deep Research feature, which needs internet to fetch live web results.

Core features ke liye nahi. Jab Ollama ke through local model chal raha ho, sab kuch offline kaam karta hai. Exception sirf Deep Research feature hai, jise live web results fetch karne ke liye internet chahiye.

Can I connect it to ChatGPT or Claude instead of a local model? Kya main ise local model ki jagah ChatGPT ya Claude se connect kar sakta hoon? ▼

Yes. Go to Settings and add your OpenAI or Anthropic API key. You get the Odysseus workspace interface with the power of frontier models. You lose the "fully offline" benefit, but the workspace itself is still self-hosted and private.

Haan. Settings mein jao aur apni OpenAI ya Anthropic API key add karo. Tumhe Odysseus workspace interface frontier models ki power ke saath milti hai. "Fully offline" benefit kho jaata hai, lekin workspace khud abhi bhi self-hosted aur private hai.

My GPU is weak — can I still use it? Mera GPU weak hai — kya main phir bhi use kar sakta hoon? ▼

Yes. Connect it to an OpenAI or Anthropic API key and you need no GPU at all — just 8GB RAM for the interface. You can also run very small models like Phi-3 Mini on CPU-only machines, just much slower.

Haan. Ise OpenAI ya Anthropic API key se connect karo aur bilkul koi GPU nahi chahiye — sirf interface ke liye 8GB RAM. Tum CPU-only machines pe Phi-3 Mini jaise bahut chhote models bhi run kar sakte ho, sirf bahut dheere.

How is this different from Open WebUI? Ye Open WebUI se alag kaise hai? ▼

Open WebUI is mainly a chat interface for local models. Odysseus bundles significantly more: autonomous agents, email management, deep research, document tools, model serving with Cookbook, and multi-model comparison — all in one workspace.

Open WebUI mainly local models ke liye ek chat interface hai. Odysseus kaafi zyada bundle karta hai: autonomous agents, email management, deep research, document tools, Cookbook ke saath model serving, aur multi-model comparison — sab ek workspace mein.
